# BazarDor

BazarDor is a responsive grocery market price website designed to help users explore daily market prices in Bangladesh, search for products, browse categories, and make informed shopping decisions.

## 🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Better Auth
* MongoDB

## ✨ Features

* 🛒 Browse grocery products and categories
* 🔍 Search for products by name
* 💰 View grocery market prices
* 🔐 User registration and sign-in
* 👤 User profile management
* 📱 Responsive design for mobile, tablet, and desktop

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/humayra-yeasmin-star8/ClickMart.git
```

### 2. Navigate to the project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Set up environment variables

Create a `.env.local` file in the project root and add the required environment variables for authentication and database access.

### 5. Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
